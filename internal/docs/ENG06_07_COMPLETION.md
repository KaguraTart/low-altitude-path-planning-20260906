# ENG-06/07 计算能力补齐实施记录

文档日期：2026-10-30。

目标：完成需求 901、902、904、909、912、913、916 中属于低空规划引擎的输入、计算、输出和验证。沿用 EG 椭球高、WKT/WGS84、v2 及 2 CPU / 2 GiB 部署。规则管理、设备下发和地面/水上引擎由平台及对应引擎负责。

## 实施顺序

- [x] 搜索与约束：Task.search 指定 ASTAR/DIJKSTRA、6/18/26 邻域、网格层级和可选扩展预算；默认无预算上限。执行爬升/下降角及天气能见度。导出真实运动穿越的全部网格，保留原编码。
- [x] 航路图：Scene.airway_graph 接收节点、方向边、非负权重、路网版本和关联航路。Task.network 指定起终节点和权重字段。计算路径节点/边序列、代价和连通分量；关闭及失效边不通行，完整运动继续执行现有安全检查。
- [x] 目标优化：Task.objectives 接收距离、时间、能耗、风险的非负权重及归一化尺度，提供显式能耗模型。搜索生成并验证候选，返回非支配方案与各项原始值、归一化值和权重；支持可选候选及迭代预算，默认无固定资源上限。
- [ ] 动态重规划：新增事件驱动接口，输入前次轨迹、当前位置/速度、剩余任务及场景变化。检查事件顺序、阈值及最大频率。复用已验路径段，受影响部分重算；接续速度纳入运动学与独立验证。返回是否触发、忽略原因、复用及重算范围。
- [x] 批量执行：提供并行数和批大小，候选阶段并行、预约阶段稳定排序；不改变安全判断。输出实际搜索/复用/目标计算指标。
- [ ] 文档与联调包：逐项更新 API、字段说明、README、需求对应表和带日期报告；本地回归及 2 CPU / 2 GiB 完整 HTTP 验证后部署、推送、PR、合入 main。

## 验证

每项先建立能改变实际结果的成功、拒绝和边界测试。完成后执行 `python -m pytest tests/ -q`，构建本地计算核及 Docker 镜像，核对运行 OpenAPI 与快照。HTTP 测试保存完整输入和响应，三套各 1000 个任务分别执行规划和独立验证。新功能增加可直接运行的专用输入。

多目标的有效性由非支配关系、归一化和目标实际改变路线的测试证明；不将重复路线包装为多解。增量重规划的复用以当前场景和时间下复核通过为前提；不将简单再次调用规划作为增量能力。完整途经网格按运动几何遍历，不以关键点或任意采样点替代。

阶段一验证：450 项测试通过。独立审查已核对角度约束的有效时间、区域绑定及原有关键点编码行为。

阶段二验证：航路图规划、连通分量、独立路径证明及非水平转弯回归已加入。图搜索与网格搜索参数分开使用；节点及边的真实几何决定连接关系。

阶段三验证：540 项测试通过。并行候选与串行结果一致，跨组冲突仍由全局预约处理；报告记录实际执行线程数。

补充航路图选路检查：最短候选的内部转弯不可行时，应继续搜索其他有效走法；相邻圆弧的切线占用共同参与可行性检查。最终证书保持独立执行。

阶段四验证：597 项测试通过。多目标联调示例生成 46 条有效候选，返回 6 条非支配完整方案；极端数值测试核对有限结果和明确错误响应。

航路候选补充验证：603 项测试通过。带进向、清理后几何尾部、途经节点进度和性能包络的有限状态用于局部筛选；延迟产生的真实边占用窗口参与预约，其他走法按有效代价继续生成。完整路线、规则和连续间隔独立复核。
