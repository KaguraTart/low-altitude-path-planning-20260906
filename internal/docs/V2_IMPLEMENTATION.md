# v2 实施与验收记录

本次按 2026-10-16 用户批准的计划实施。对外接口以 `docs/API.md` 和运行服务的 OpenAPI 为准。

## 固定决策

- v1 保留；v2 使用 JSON + WKT、WGS84 经度/纬度和显式高度基准。
- `route_mode`: `strict`（默认）、`prefer`、`free`；严格模式仅支持显式接驳。
- 全部 20 类规则执行；环境、区域引用和飞机状态由上游提供，算法生成方案。
- 场景预注册后，8 CPU / 8GB，三套各 1000 个已知可行任务，各 10 轮完整规划均 ≤10s。
- 基准种子 20261016；固定数据与参考调度后才优化。不得缓存任务答案代替规划。
- 地图 5×5km、局部 z=0..300m、25×25×10m、3600s、4 个性能配置。
- 场景上限：1000 障碍、20 管制区、200 航路、50000 几何顶点、每对象 10 个有效区间。
- 每套至少 200 个不同任务在未协调独立路线中有连续冲突，最终 1000 条必须全部通过独立验证。
