# 算法设计说明

## 3.25 多维时空大规模并行规划算法

### 模块一：多维时空约束建模

**核心思想**：将三维物理空间 + 一维时间构建为四维时空网格 `(x, y, z, t)`，每个时空格表示"某飞行器在某时刻能否出现在该位置"。

- **空间离散化**：按 `dx, dy, dz` 分辨率将连续空间划分为规则网格
- **时间离散化**：按 `dt` 时间步长将规划时域离散化
- **约束表达**：
  - 空域边界 → 网格边界
  - 静态障碍物 → 所有时间步均占用的空间格
  - 动态障碍物 → 仅在特定时间步占用的时空格
  - 飞行器性能 → 邻域移动的速度/爬升率约束

### 模块二：静态与动态避障

**静态避障**：
- 建筑物、地形、通信塔等固定障碍物
- 使用精确包围盒（AABB）标记占用网格
- 障碍物数据来源：城市 GIS、DEM 高程、通信设施台账

**动态避障**：
- 其他飞行器、鸟群、移动车辆
- 基于时间戳轨迹，线性插值获取任意时刻位置
- 每个动态障碍物带安全半径，在时空网格中标记为膨胀占用区

### 模块三：多源规划数据融合

`ObstacleDataFusion` 类实现：
- 多数据源注册（GIS、雷达、飞行计划、生态监测）
- 按优先级合并，冲突时高优先级覆盖低优先级
- 数据去重（相同位置 + 相同类型）
- 数据质量报告与警告

### 模块四：大规模并行规划引擎

`ParallelPlanner` 类实现：
- 基于 `concurrent.futures.ThreadPoolExecutor` 的多线程并行
- 按任务优先级排序，高优先级先规划
- 多航点任务分段规划后拼接
- 飞行器间冲突检测（时间对齐 + 最小安全间隔检查）
- 规模验证：支持百级任务批量规划

### 核心算法：多维时空 A*

**状态空间**：`(ix, iy, iz, it)` 四维网格坐标

**搜索策略**：
- 6 邻域空间移动（上下左右前后）+ 等待动作
- 每次动作推进一个时间步
- 启发函数：曼哈顿网格距离 × 时间步长（可采纳）
- 代价函数：时间步长 + 微小距离惩罚（打破平局）
- Closed set 避免重复扩展

**关键优化**：
- 精确包围盒障碍物标记（不浪费上方空域）
- 过期条目跳过（stale entry check）
- 速度约束过滤不可行动作

## 3.26 智能飞行线路规划算法

> 注：气象相关功能按需求标注"气象相关的做不了"，本实现不包含气象数据融合。

### 模块一：地理管制数据融合

- 静态障碍物（建筑物、禁飞区）
- 动态障碍物（其他飞行器轨迹）
- 空域边界约束
- **不包含**：气象数据（风、雨、能见度等）

### 模块二：飞行器性能与任务约束建模

`AircraftPerformance` 类定义：
- 运动学约束：最大速度、爬升率、下降率、转弯率、加速度
- 几何约束：旋翼半径、安全裕度
- 续航约束：最大飞行时间、最大航程
- 运行高度限制

`FlightTask` 类定义：
- 航点序列（含起点、途经点、终点）
- 时间窗约束
- 任务优先级
- 多目标优化权重

### 模块三：多目标航线优化

`RouteOptimizer` 类实现四目标优化：

| 目标 | 说明 | 权重示例 |
|------|------|----------|
| distance | 总航程最短 | 0.2-0.4 |
| time | 总飞行时间最短 | 0.2-0.6 |
| risk | 距障碍物风险最低 | 0.1-0.5 |
| energy | 估算能耗最低 | 0.1-0.2 |

**优化流程**：
1. 时空 A* 生成初始无碰撞路径
2. 三次样条插值平滑轨迹
3. 碰撞检测（平滑后若穿模则回退原始路径）
4. 性能约束修正（速度、爬升率、转弯率）
5. 多目标指标计算与加权评分

### 模块四：航点生成与结果解释

**航点提取**：
- 按最小间距（默认 80m）采样
- 航向变化超过 15° 时插入航点
- 起点标记 takeoff，终点标记 land

**结果解释**：
- 综合加权得分
- 各优化目标的贡献度分析
- 最近障碍物距离
- 航点数与飞行参数

### 模块五：规划服务封装与综合评测

- 统一 `PlannedRoute` 输出格式
- 批量规划结果 `PlanningResult`
- JSON 序列化输出
- Markdown 规划报告生成
- 可视化（3D 静态图 + 交互式 HTML + 风险热力图）
